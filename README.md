# End-to-End ML/DL Portfolio

This repository contains my machine learning and deep learning practice work, organized topic by topic. I built this while transitioning into AI/ML, covering everything from basic data analysis to deep learning and computer vision.

## About this repository

Each folder here represents a concept I studied and implemented hands-on, using real datasets. I did not just follow tutorials - I worked through the math and logic behind each algorithm, tested them on different datasets, and compared results. This practice directly helped me move into an AI Engineer role, where I now work on deep learning models in production.

## What's inside

**Data Analysis**
- Pandas based data analysis
- Exploratory Data Analysis (Titanic dataset, Cars dataset)
- Outlier detection and handling
- One hot encoding for categorical data

**Regression**
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression
- ElasticNet Regression

**Classification**
- Logistic Regression
- Naive Bayes (Gaussian and Multinomial)
- KNN
- Decision Tree
- Random Forest
- SVM with K-Fold cross validation

**Clustering and Association Rules**
- K-Means Clustering
- Apriori algorithm

**Model Evaluation**
- Comparing multiple models on the Cleveland heart disease dataset

**Deep Learning**
- Artificial Neural Networks built from scratch and using TensorFlow/Keras
- CNN for image classification (MNIST)
- RNN/LSTM for sentiment analysis and stock price prediction

**Computer Vision**
- OpenCV basics (image processing, contours, resizing)
- Face and eye detection using Haar cascades
- Object detection using YOLO

**NLP**
- Sentiment analysis on movie reviews

## Tools used

Python, Scikit-learn, TensorFlow, Keras, Pandas, NumPy, OpenCV, Matplotlib, Seaborn

## Why I built this

I wanted a strong foundation in ML and DL before working on real AI projects. Instead of jumping straight into advanced models, I went through each core algorithm one by one, understood how it works, and implemented it myself. This structured practice is what gave me the confidence to take on more advanced work like deep learning models for computer vision and generative AI.
